# Provider icons

`groq.svg` and `mistral.svg` are from
[`@lobehub/icons-static-svg` 1.102.0](https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.102.0),
using the upstream `groq.svg` and `mistral-color.svg` assets. Web-only sizing
and style attributes were removed; the original paths are preserved.
