# Saymore 本地 ASR Beta 发布决策地图

状态：当前有效，按 macOS 完整闭环后再进入 Windows 的顺序开发 日期：2026-08-03

## 目标与边界

尽快让普通用户完成“下载模型 -> 选择本地识别 -> 离线听写 ->
失败可恢复”的完整闭环。首版直接使用上游社区的官方固定制品，不建设 Saymore OSS
或镜像，不训练、微调或自行量化。先完成 macOS 的四个模型闭环，再进入 Windows
适配与验证。模型页“语音模型”分类固定适配 Paraformer、Whisper large-v3-turbo、
Qwen3-ASR 1.7B 和 SenseVoiceSmall 四个本地 ASR
模型；它们不是四个产品方向，也不与 文本润色模型混排。SenseVoiceSmall
固定排在最后一个本地模型位置，即 Qwen3-ASR 之后、火山引擎等云端 API 之前。

## Beta 必须具备

- 在独立模型页的“语音模型”分类展示 Paraformer、Whisper large-v3-turbo 和
  Qwen3-ASR
  1.7B，并明确大小、来源、许可证、适用场景、流式输出能力和“音频不离开设备”。
- 语音识别 Provider 先展示 Saymore 云和当前平台的系统内置服务，随后依次展示
  Paraformer、Whisper large-v3-turbo、Qwen3-ASR 1.7B、SenseVoiceSmall、
  火山引擎和自定义接口。
- 四个本地模型平级展示，不默认推荐、不预选、不自动下载；未来 Saymore 自有云端
  ASR 也由用户主动选择，不自动取代当前 Provider。
- 允许多个本地模型同时安装，但只有一个当前
  Provider；模型页显示单模型和全部本地模型的磁盘占用。
- 当前模型不可直接删除；用户必须先成功切换到另一个
  Provider，避免听写能力被意外置空。
- 四个模型都必须在 macOS 与 Windows
  完成安装、加载和真实听写闭环；第一版不使用“即将推出”占位，也不以单个模型完成代替四模型交付。
- 可信模型元数据随签名应用内置，不为首版建设远程模型注册表。
- 模型只从上游官方固定版本或提交下载，不使用浮动最新版地址，也不通过 Saymore
  自建 OSS 或镜像分发。
- 下载失败可重试，哈希不匹配和残缺文件绝不激活。
- 下载中可暂停并保留断点，暂停后可继续或主动取消；网络中断或应用退出同样保留断点，应用重启后保持暂停。上游不支持续传或制品变化时明确提示并从头下载。
- 最多同时下载两个模型；其余请求进入持久先进先出队列，用户可以取消活动或排队任务。
- 单次下载失败先静默自动重试三次；仍失败时弹窗提供“继续下载”和“稍后”，保留临时分片。磁盘不足时同时提供“管理空间”。
- 主动取消下载会删除队列记录和全部临时分片；网络中断或应用退出仍保留断点。
- 下载前检查峰值磁盘需求并显示缺口；空间不足不创建任务，途中耗尽保留断点但不激活模型。
- 设备能力检测只在本地读取操作系统、架构、物理内存、必要 CPU
  指令集和可用推理加速后端，并与每个模型经过目标设备实测的最低和推荐要求比较；检测信息不默认上传。
- 已知硬不兼容或低于会导致加载失败、进程崩溃或明显系统风险的最低要求时禁用安装；达到最低要求但低于推荐要求时允许用户确认后安装并明确警告。
- 模型加载失败、录音取消、无有效语音和识别失败都有明确状态，不产生错误投递。
- 新选择通过校验、加载和最小自检后才原子生效；失败时不跨本地模型或云端自动回退。
- 下载、安装和启用是独立动作。下载完成只新增本地可用模型，不加载模型、不改变当前
  Provider；用户点击“使用此模型”且加载成功后才切换。
- 本地识别不依赖网络；云端 ASR 保留为用户主动选择的替代 Provider。
- macOS 与 Windows 使用相同模型身份和能力声明，并同步通过发布门槛。

## Beta 后再做

- 模型训练、微调或自行量化。
- Saymore 自建 OSS 或镜像、远程签名适配清单、模型“检测并更新”和手动离线导入。
- 完整 VAD/端点检测优化、公开 benchmark 服务、模型目录、社区和排行榜。
- 为所有语言和硬件档位作统一承诺；首版只声明实际通过测试的能力。

## 已知现状

- 应用层已经定义流式识别会话契约；macOS 桌面运行时可按持久化 Provider
  选择创建云端、系统、Paraformer、Whisper、Qwen3-ASR 或 SenseVoice Adapter。
- Paraformer Q8 已有 `crates/infra` 生产 Adapter。固定 revision 在 Apple Silicon
  上一次加载后连续完成两次真实听写，结果一致且无结尾重复或截断；取消与空结果由确定性契约测试覆盖。
- Paraformer macOS 使用 Hugging Face 固定 revision 下载三份制品，支持 Range
  断点、手动暂停和继续、主动取消清理、一次请求加三次自动重试、逐文件大小和
  SHA-256 校验、临时目录原子激活及损坏恢复。下载完成后保持当前
  Provider；当前模型必须先切换 Provider 才能删除。
- Paraformer 标点处理可在 LLM 润色与本地 CT-Transformer 之间切换。官方中英 INT8
  标点模型作为独立可选制品下载并校验，只处理 final，不修改流式 partial；本地模式
  随 Paraformer 持久化启动，切离 Paraformer 或切回 LLM 时释放。模型详情弹窗固定
  外壳尺寸，正文溢出时支持滚轮和触控板滑动，且不显示滚动条。
- Whisper large-v3-turbo macOS 固定 `2ca6ff69fc878651b770880507669577ac41c2ff`
  revision 的两份 INT8 ONNX 与词表，总计 988.59
  MiB。它复用相同下载和安装器，使用 sherpa-onnx `OfflineRecognizer`：录音中缓存
  PCM，结束时离线解码，不伪造 partial；超过 30
  秒的音频按顺序分段且不丢样本。Apple Silicon 真机一次加载后连续两次识别 6.62
  秒固定音频，文本一致，推理耗时分别为 2.99 秒和 3.08 秒。
- Qwen3-ASR 1.7B macOS 固定 `cb045ad80b8970c9d411d463e5b78991a566596c` revision
  的三份 ONNX 和 tokenizer 三文件，总计 2.24 GiB。它通过 sherpa-onnx
  `OfflineQwen3ASRModelConfig` 直接加载，不引入 Python 或 MLX。Apple Silicon
  实测 加载约 1.9 至 4.0 秒，常驻内存约 4.3 GB；3.9 秒中文两次推理为 2.94 秒和
  2.87 秒，65 秒中文两次推理为 25.83 秒和 33.08
  秒，输出一致且跨段无重复或截断。粤语夹英文 样本两次一致；纯多语言 codeswitch
  样本质量未达参考文本，不能宣传普遍多语言混输质量。
- SenseVoiceSmall macOS 固定 `2365baeacb507f821a0c8120fcee3d484dba7a07` revision
  的 INT8 ONNX、词表、Silero VAD 和许可证引用，总下载量 229.07 MiB。它通过
  sherpa-onnx `OfflineSenseVoiceModelConfig` 加载，使用自动语种和原生
  ITN/标点，支持中、粤、英、日、韩五语，录音结束后由 VAD 按语音段生成
  final，单段最长 30 秒。Apple Silicon 真机使用
  上游中文样本连续两次均输出“开放时间早上 9 点至下午 5 点。”，首次加载约 0.35
  秒，两次推理均约 0.18 秒；探针进程峰值常驻内存约 573 MiB。
- 已安装模型存储保存固定模型身份、版本、路径和校验时间，并随模型删除清理对应元数据。
- 本地模型资源指标不再由 UI 手填：下载大小由锁定 manifest 中的文件字节数汇总，
  已安装占用递归统计对应 revision
  目录中的普通文件，并在安装、删除后刷新应用总占用。
  界面统一按二进制单位换算且保留两位小数；因此下载大小与磁盘占用可能因 Saymore
  校验记录或目录中的其他本地文件而有少量差异。
- 模型页已使用提供商卡片和配置弹窗承载火山引擎及 OpenAI-compatible 自定义 ASR
  的真实配置闭环；自定义服务支持从兼容的 `/models` 端点获取模型列表并选择模型，
  同时保留手动模型 ID 作为不提供模型列表端点时的兼容路径。所有构建都展示四个
  平级本地模型的详情和规划资源指标。本地模型弹窗已经统一未下载、下载中和已下载
  未下载、下载中、已暂停、正在取消和已下载五种生命周期视觉状态，以及下载、暂停、继续、取消、删除、识别测试和“使用此模型”的
  UI 接口；macOS 已为 四个本地模型在 macOS 均启用这些操作。
  本地模型切换在后台加载，开关在加载期间禁用重复操作并显示旋转状态；成功加载后才原子切换
  Provider，失败时保留原选择并就地显示错误。运行内存未采样时显示文字化估算值；成功加载后以绿色
  状态点显示 Saymore 进程的当前常驻内存，本地模型详情弹窗可见时每 2
  秒刷新一次，关闭弹窗后停止
  查询。瞬时采样失败时保留上一次成功值，不阻断模型使用。切换离开本地 Provider
  时释放其运行时 缓存并撤销绿色实时占用状态；再次启用必须重新进入后台加载状态。
- Qwen3-ASR 当前只批准为研发制品。ModelScope 转换仓库缺少完整转换 provenance，
  现有公开资料也不能证明 INT8 相对
  BF16“几乎无精度损失”；正式镜像和质量文案仍受此约束。
